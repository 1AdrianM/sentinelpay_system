Hexagonal Architecture: Logic is decoupled from Infrastructure
Domain-Driven Design

The heart of the system. Contains pure business logic, rules, and aggregates (Transaction, Incident, RiskProfile) without any framework dependencies.

  • Rich Domain Model
  • Ubiquitous Language
  • Isolated Business Rules
Hexagonal Architecture

Ports and Adapters pattern. The core is surrounded by an application layer that defines interfaces for external communication.

  • Framework Independence
  • Easy to Test (Unit Tests)
  • Swap DBs or UIs easily
Reactive Web with HTMX

Modern frontend approach using HTMX to provide SPA-like responsiveness without the complexity of a heavy JS framework.

  • Low Complexity
  • Server-Side State
  • Fast Development
